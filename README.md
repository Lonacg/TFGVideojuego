## Prueba del juego online
Enlace a Itch.io para jugar en el navegador sin necesidad de descargar ni instalar nada:
https://lonacg.itch.io/buscando-a-euler

## Prueba del juego desde Windows
Descargar la carpeta Unity/TFG/Builds/Windows y ejecutar el archivo "Buscando_a_Euler.exe"

## Prueba del juego desde Linux
Descargar la carpeta Unity/TFG/Builds/Linux y ejecutar el archivo "Buscando a Euler.x86_64"

## Prueba del juego desde Mac
Descargar la carpeta Unity/TFG/Builds/Mac. A continuación, se debe marcar el archivo binario como ejecutable, ya que la build ha sido creada desde Windows. Para ello, hay que seguir los siguientes pasos:
- Abrir la terminal y navegar hasta la dirección de la carpeta descargada con el comando "cd" (por ejemplo, cd /Unity/TFG/Builds/Mac)
- Ejecutar el siguiente comando: chmod +x Buscando_a_Euler.app/Mac.app/Contents/MacOS/Buscando_a_Euler  

Una vez realizado, ya se puede abrir el ejecutable Buscando_a_Euler.
